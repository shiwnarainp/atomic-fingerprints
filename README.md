# Atomic Fingerprints

An interactive bright-line spectra simulation for NYS Regents Physical Science: Chemistry (HS-PS1-1, HS-PS4-4).

Students:

1. View hydrogen's spectrum through a virtual spectroscope.
2. Trigger hydrogen electron transitions (n = 1–6) and build the visible Balmer spectrum.
3. Compare the emission spectra of H, He, Ne, Na, and Hg.
4. Identify unknown elements and mixtures in the Spectral Detective challenges.
5. Identify elements in a simulated star's absorption spectrum.
6. Take a 10-question Regents-style knowledge check.

Open `index.html` in any browser. It is one self-contained file and needs no build step.

Color names follow the visible-light bands on page 2 of the 2025 NYS Reference Tables for Physical Science: Chemistry.
